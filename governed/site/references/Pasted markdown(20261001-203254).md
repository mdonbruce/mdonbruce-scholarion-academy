\## 4. PROGRAM #15 — ADVANCED CERTIFICATE IN AGENTIC AI ENGINEERING (WEEKEND INTENSIVE) — DETAILED SPEC



\### 4.1 Key facts

\- \*\*Format:\*\* 10 weekends. Live online Saturday and Sunday, 3 hours each (60 live hours). Expect a further \~4–6 hours/week of self-paced lab work.

\- \*\*Batches:\*\* rolling weekend cohorts every 4–6 weeks. Each batch sets a time-zone-specific schedule (e.g., an Americas-morning batch and an evening batch). Cohort size is capped (set by admin) so instructors and mentors can give individual attention.

\- \*\*Prerequisites:\*\* working Python and comfort calling APIs. No prior agent-framework, Docker or Kubernetes experience needed.

\- \*\*Pedagogy:\*\* about 70% hands-on. Every live session is a guided build: demo → lab → checkpoint.

\- \*\*Credentials:\*\* Certificate of Completion, plus a Graded Performance Certificate and an "Agentic AI Engineering" capstone badge (Open Badges 3.0, verifiable via Scholaris).

\- \*\*Completion requires:\*\*

  - All 20 live modules attended (or recordings reviewed, with the lab submitted)

  - All module assessments passed

  - Capstone scoring at least 70/100 on the mentor rubric, with a live demo defense

  - Final certification knowledge check passed (2 attempts; free remediation support between attempts)



\### 4.2 Weekend-by-weekend plan (20 live modules — write original titles and content)

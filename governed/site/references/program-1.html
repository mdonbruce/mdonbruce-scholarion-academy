Curriculum

Week-by-week learning path

WeekFocus
0 (optional)Python and tooling refresher: VS Code, Colab, Git, virtual environments, API basics
1Agentic systems: autonomy levels, agent loops, and when not to use agents
2LLM foundations for builders: tokens, context, sampling, structured output, cost and latency
3Instruction design for agents: system prompts and output schemas
4Tool use and function calling: error handling and idempotent tools
5Retrieval systems: embeddings, chunking, vector stores, hybrid search and reranking
6Agentic RAG: routing, query planning, self-correction and citation grounding
7Planning and reasoning patterns: reason-act loops, plan-and-execute and reflection
8Memory and context management: short/long-term memory, summarization and context budgets
9Midterm project plus Block A exam
10Small language models for agents: local inference and SLM/LLM routing
11Multi-agent architectures: orchestrator–worker, hierarchical, critic/reviewer and handoffs
12Frameworks lab: graph-based orchestration and role-based crews; versions verified at build time
13Tool and context protocols such as MCP: secure servers and clients
14Agentic coding: repository tasks, test-first workflows and review gates
15Evaluation: task success, trajectory evaluation, calibrated LLM-as-judge and regression suites
16Observability, security and guardrails: tracing, injection defense, permissions, sandboxing and human oversight
17Deployment: APIs, containers, cost controls, monitoring and rollback
18Capstone defense and demo day
Applied work

Projects and capstone

Midterm

Dual-Source Market Insight Agent

Combines structured financial data and unstructured filings/news using synthetic or public-domain sources into a cited insight report.

Applied project

Autonomous Research Analyst Agent

Multi-step research with planning, web/document tools, source grading, citations and confidence levels.

Capstone

Loan Underwriting Assistant

A multi-agent recommendation package for a human underwriter using synthetic applicants; includes audit trail, fair-lending bias testing across protected attributes, adverse-action reason codes, and an explicit human-decision step. The system never issues final credit decisions.

## 2. SELF-PACED PRODUCT STANDARD

### 2.1 Product types
| Type | Size | Credential |
|---|---|---|
| **Guided Project** | 1–2 hours, one hands-on build in the Cloud Lab | Completion badge |
| **Short Course** | 4–6 modules, 8–16 hours | Course Certificate |
| **Specialization** | 3–6 short courses plus a capstone project | Specialization Certificate plus badge |
| **Professional Certificate** | 4–8 short courses, job-role aligned, plus a portfolio capstone | Professional Certificate (Scholaris) plus badge |

### 2.2 Short-course module structure (every module)
- 4–8 short videos (6–10 min each), captioned, with transcripts and chapters
- Readings: original notes plus cited public papers and docs
- **Ungraded lab:** Student Starter TODO notebook, with the Instructor EXECUTED notebook revealed after submission
- **Graded quiz** from an item bank: randomized, explanations shown, 80% pass, retakes with a cooldown
- **Graded programming assignment**, autograded in the Scholaris Cloud Lab with Learning Tools Interoperability (LTI) grade passback (Builder courses)
- Discussion prompt
- **Hands-on In-Class Activity** (Academy template) for instructor-led or corporate cohorts that license the course. The student self-paced edition replaces the APA submission with an autograded deliverable; the instructor edition keeps the full template and answer key.

### 2.3 Course and credential rules
- **Final project per course:** peer-reviewed (minimum 3 reviews, rubric-based) or autograded.
- **Mapping to the Scholaris course standard:** a specialization or professional certificate is mapped as one or more **10-week standard blocks** for credit-equivalence purposes. Record the equivalent assignments, labs, projects and quizzes so self-paced credentials can transfer into the live programs.
- **Pacing:** suggested deadlines with automatic resets, Course Pacing support, and sequential module locking that is optional per course.
- **Access models** (decision required, sandbox):
  - (a) Free audit: content visible, graded items locked
  - (b) Paid per course or credential
  - (c) "Scholaris Plus" subscription
- **AI support:** the Scholaris AI Teaching Assistant coaches but never completes graded work.
- **Stacking and transfer:** completed specializations and professional certificates waive the equivalent modules in live programs (#1, #2, #15, #16, #18). Record every rule in the catalog consolidation table.

### 3.1 Course-level design requirements (write all titles and content originally)

**#28 RAG & Agentic AI Engineer (Professional Certificate, 8 courses)**
1. LLM application foundations: APIs, prompting, structured output
2. Building LLM apps with a chain/orchestration framework and a simple UI
3. Embeddings and vector databases
4. RAG pipelines: chunking, retrieval, reranking, evaluation
5. Advanced and agentic RAG: routing, self-correction, GraphRAG intro
6. Building tool-using agents
7. Multi-agent systems and MCP integration
8. **Capstone:** production-shaped RAG + agent application with evaluation, guardrails and deployment

**#29 AI Agent Developer: Foundations to Applications (Professional Certificate, 4 courses)**
1. Agent fundamentals and design: autonomy, tools, memory, planning
2. Building agents with an agent SDK: provider-neutral core plus one cloud agent service lab
3. Multi-agent orchestration and enterprise integration: APIs, identity, permissions, connectors
4. **Deploying and operating agents**, with a capstone: deploy, monitor, evaluate and govern an enterprise agent (Scholaris/Haven sandbox scenario)

**#30 AI Agents & Agentic Systems in Python (Specialization, 3 courses)**
1. Agents in Python from first principles: the agent loop, tool calling, memory, without a framework
2. Agent architecture patterns: planner/executor, router, reflection, multi-agent, safety boundaries
3. Agentic workflows with a framework, with a capstone: a Python agent that automates a multi-step knowledge-work task

**#31 AI Agent Developer — Extended (Specialization, 6 courses)**
- Courses 1–3 = #30
- 4. Prompt engineering for agents and assistants
- 5. AI-assisted data analysis: an agent with a code-execution tool, with validation of results
- 6. **Trustworthy generative AI:** reliability, verification, bias, privacy, disclosure
- **Capstone:** a trustworthy agent with an evaluation report

**#32 Agentic Design Patterns (Short Course, 5 modules)**
1. What makes AI agentic; levels of autonomy
2. Reflection and self-critique
3. Tool use
4. Planning
5. Multi-agent collaboration plus **error analysis and evaluation-driven development**

Each module has a framework-free Python lab.

**#33 Agentic AI Engineering with Graph Orchestration & MCP (Specialization, 3 courses)**
1. Agentic pipelines with chains, tools and structured data validation
2. Stateful graph agents: routing, persistence, human-in-the-loop, debugging, recovery
3. MCP-powered agentic systems: servers, clients, interoperability, security, scaling
- **Capstone:** a graph agent consuming two custom MCP servers

**#34 Agentic AI for Leaders (Short Course, no code)**
- What agents can and can't do
- Use-case identification and process redesign
- Risk, governance and human oversight
- Build/buy/partner decisions and cost
- Leading adoption
- **Final project:** agent opportunity brief with a governance plan

**#35 Guided Project — Stateful Agents with Graph Workflows**
Build a routing graph with tool nodes, a checkpoint and a human approval step.

**#36 Guided Project — Multi-Agent Teams with Role-Based Crews**
Build a 3-agent researcher/analyst/writer crew in sequential and hierarchical modes, and compare the outputs with a rubric.

**#37 AI & ML Foundations with TensorFlow and PyTorch (Specialization, 4 courses)**
1. Python and data for ML: Gaddis-aligned refresher, NumPy, pandas, visualization
2. Supervised and unsupervised learning with scikit-learn: **data training pipelines**, feature engineering, cross-validation
3. **Model evaluation:** metrics, confusion matrices, ROC/PR, calibration, error analysis, fairness checks
4. First neural networks in **PyTorch and TensorFlow/Keras** (parallel labs)
- **Capstone:** end-to-end model with an evaluation report and model card

**#38 Neural Networks, Deep Learning & NLP for Agent Builders (Specialization, 4 courses)**
1. Deep learning: backpropagation, optimizers, regularization, training at scale (PyTorch and TensorFlow labs)
2. CNNs and transfer learning
3. **NLP:** text processing, embeddings, sequence models, attention and transformers
4. From transformers to LLMs and agents: fine-tuning a small model, embeddings for retrieval, how LLMs power agents
- **Capstone:** fine-tuned NLP model plugged into a retrieval agent as a tool

## 3. LEARNING OUTCOMES (rewrite originally as 5–6 measurable competencies)

Learners will be able to:
1. Engineer single agents with memory, tool use and explicit reasoning loops.
2. Build retrieval layers (embeddings, vector indexes, hybrid retrieval) and measure their effect on agent output quality.
3. Design multi-agent systems with defined roles, coordination protocols and failure handling.
4. Integrate external APIs and tools safely, using typed schemas, permissions and error handling.
5. Evaluate, guard, log and observe agent systems so reliability can be measured and improved.
6. Deliver an end-to-end agentic system for a real-world problem and defend its design.

## 4. WEEK-BY-WEEK DESIGN (write original module titles)

The schedule cadence is a live session mid-week, Lab A the next day and Lab B the day after. Times are published in ET with an automatic local-time display.

| Week | Theme | Live session focus | Lab A | Lab B |
|---|---|---|---|---|
| 1 | From LLMs to agents | Model capabilities and limits, context, structured output, multi-provider APIs, what makes a system agentic | Multi-provider client with structured output and cost/latency logging | Baseline "agent-less" pipeline vs simple tool-calling agent on the same task |
| 2 | Agent architecture | Memory types, tool interfaces, reasoning-act loops, plan-and-execute, stopping conditions | Tool-using agent with typed tools, retries and step limits | Add short- and long-term memory; measure effect on multi-turn tasks |
| 3 | Retrieval-augmented agents | Embeddings, chunking, vector indexes (local and managed), hybrid search, reranking, agentic retrieval decisions | Build and benchmark two vector indexes on the same corpus | Agent that decides when and what to retrieve; grounded answers with citations |
| 4 | Advanced reasoning and multi-agent concepts | Chain-of-thought, self-consistency, tree-search reasoning, reflection; multi-agent patterns (debate, critic, orchestrator–worker) | Implement a tree-search reasoning solver; compare against linear reasoning | Two-agent critic/generator loop with a quality rubric |
| 5 | Multi-agent workflows in practice | Role-based crews vs stateful graphs; coordination, handoffs, shared state, human-in-the-loop | Role-based crew for a research-and-report task | Same task as a stateful graph with an approval gate; compare reliability and cost |
| 6 | Evaluation, guardrails and observability | Task and trajectory evaluation, LLM-as-judge calibrated against human labels, prompt-injection defense, input/output validation, logging, tracing, cost monitoring | Evaluation suite plus tracing for the Week 5 system | Red-team with injection attacks; add guardrails; rerun the evaluation and report the deltas |
| 7 | Capstone | — | Capstone build clinic and peer design review | **Final presentations:** demo, architecture, evaluation results, limitations |

## 6. CAPSTONE

Learners independently build an end-to-end agentic system from a **preselected project list**. Each project uses synthetic data and a Scholaris/Haven sandbox. Original briefs:
1. **Admissions navigation assistant:** multi-agent; the OakHaven demo catalog with retrieval over program and policy docs; escalates to a human.
2. **Guest-services orchestrator:** Oak Haven Lodging sandbox; booking lookup, request routing, approval gate for refunds.
3. **Pharmacy-order status agent:** MediGrid sandbox, **non-clinical only**; order, inventory and delivery tools, with strict refusal of medical advice.
4. **Support triage crew:** HavenConnect sandbox; classify, retrieve, draft and quality-check replies.
5. **Research brief generator:** planning agent plus retrieval plus critic, with citation-coverage evaluation.
6. **Code-review assistant:** repository tool access through scoped permissions; test-first suggestions; human merge decision.

**Required in every capstone:**
- Architecture diagram
- At least 2 external tools/APIs with typed schemas
- Retrieval layer (where relevant)
- Multi-agent or graph coordination
- Evaluation suite with baseline comparison
- Guardrails, tracing and a cost report
- Limitations section
- 10-minute presentation

Graded against a pass-threshold rubric.

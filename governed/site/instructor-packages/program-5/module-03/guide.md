# Instructor guide: Review predictive actions

Objective: O3: Evaluate ordinary, ambiguous and adversarial cases against a baseline.

Timing: 10-minute setup, 20-minute implementation, 20-minute challenge, 15-minute critique, 5-minute wrap-up.

Emphasize: The approved review and authorization process

Common mistake: Act automatically on above-average scores. Ask which assumption failed.

Worked interpretation: A score is uncertain and must be interpreted against action costs. Separate false positives from false negatives. A configured threshold stands in for model output in this simulation.

Discussion: post one failure and critique one peer with evidence.

Do not treat a rules simulation as a live model or production service. Review the claim against reproduced outputs.

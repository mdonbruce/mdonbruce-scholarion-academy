# Instructor guide: Validate structured outputs

Objective: O1: Map decision boundaries and evidence requirements for an operations analysis team.

Timing: 10-minute setup, 20-minute implementation, 20-minute challenge, 15-minute critique, 5-minute wrap-up.

Emphasize: Syntactic validity only

Common mistake: That the content is factually correct. Ask which assumption failed.

Worked interpretation: Parseable output is not automatically correct. Check required fields, types, ranges and allowed categories. Generated identifiers and tool arguments remain untrusted until independently validated.

Discussion: post one failure and critique one peer with evidence.

Do not treat a rules simulation as a live model or production service. Review the claim against reproduced outputs.

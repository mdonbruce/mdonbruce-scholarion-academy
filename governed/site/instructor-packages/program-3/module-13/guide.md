# Instructor guide: Preserve evidence boundaries

Objective: O3: Evaluate ordinary, ambiguous and adversarial cases against a baseline.

Timing: 10-minute setup, 20-minute implementation, 20-minute challenge, 15-minute critique, 5-minute wrap-up.

Emphasize: Separating an exception from its condition

Common mistake: Making all source facts invalid. Ask which assumption failed.

Worked interpretation: Chunking trades context against noise. Splitting conditions from exceptions can change meaning. Overlap preserves continuity but duplicates evidence and increases retrieval volume.

Discussion: post one failure and critique one peer with evidence.

Do not treat a rules simulation as a live model or production service. Review the claim against reproduced outputs.

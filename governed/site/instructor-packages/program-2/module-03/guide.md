# Instructor guide: Build a measurable baseline

Objective: O3: Evaluate ordinary, ambiguous and adversarial cases against a baseline.

Timing: 10-minute setup, 20-minute implementation, 20-minute challenge, 15-minute critique, 5-minute wrap-up.

Emphasize: The same examples and metric definitions

Common mistake: Replacing difficult examples after seeing results. Ask which assumption failed.

Worked interpretation: Keep baseline and candidate evaluations on the same held-out examples. Define the cost of false acceptance and unnecessary review. A simple rule is a useful reference, even when a later model is more complex.

Discussion: post one failure and critique one peer with evidence.

Do not treat a rules simulation as a live model or production service. Review the claim against reproduced outputs.

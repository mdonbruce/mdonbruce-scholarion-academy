# Instructor guide: Support non-clinical operations

Objective: O5: Defend a non-clinical operations support portfolio with reproducible evidence and limitations.

Timing: 10-minute setup, 20-minute implementation, 20-minute challenge, 15-minute critique, 5-minute wrap-up.

Emphasize: Synthetic scheduling support

Common mistake: Selecting treatment. Ask which assumption failed.

Worked interpretation: Administrative scheduling and documentation can use bounded support, but ambiguous information must route to trained people. Never use real patient data or recommend diagnosis or treatment here.

Discussion: post one failure and critique one peer with evidence.

Do not treat a rules simulation as a live model or production service. Review the claim against reproduced outputs.
